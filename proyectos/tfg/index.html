Por qué este proyecto

Toco el clarinete en la Banda Municipal de Jamilena y en el Coro y Orquesta Diocesanos de Jaén. En las agrupaciones musicales mucha de la organización va por mensajes sueltos, hojas de cálculo y memoria. Quiero hacer una herramienta pensada para ellas, partiendo de lo que veo cada semana desde dentro.

Lo hago desde cero, sin partir de una plantilla, porque así tengo que tomar y justificar cada decisión de diseño: el modelo de datos, la API y la experiencia en la app.

Plan de trabajo

  1. Análisis. Qué necesitan las agrupaciones y qué debe hacer la primera versión.
  2. Diseño. Modelo de datos y contrato de la API.
  3. Backend. API con FastAPI sobre PostgreSQL, con pruebas.
  4. App. Cliente en Flutter conectado a la API.
  5. Pruebas y memoria. Validación con uso real y redacción del TFG.
