Esta web y mi CV

Una web personal escrita a mano y un CV que se genera en español y en inglés desde un único archivo. Ambos usan mi marca personal y viven en el mismo repositorio.

La web

HTML y CSS escritos a mano, sin frameworks, publicados con GitHub Pages. El único JavaScript es el de la gráfica del radioenlace, y la página se entiende igual sin él.

  • Español e inglés como páginas estáticas, enlazadas entre sí.
  • Modo claro y oscuro automático según la configuración del sistema.
  • Accesible con teclado, con foco visible, y respeta a quien tiene las animaciones reducidas.
  • Se adapta del móvil a pantallas grandes con una sola hoja de estilos.

La marca

Diseñé mi propio logotipo: «liebana» en Bricolage Grotesque con un rombo inclinado sobre la e. El rombo es lo único de color, en ámbar, y aquí lo uso también como marco de la foto y como marcador en la línea de tiempo.

Los colores salen de Jamilena, mi pueblo: el verde del olivar para los bloques oscuros y el blanco de cal para el fondo.

El CV en Typst

Escribo el CV en Typst, un sistema de composición de documentos con código. Un único archivo genera la versión en español y en inglés según el idioma que le paso, con las mismas fuentes y colores que la web.

Cada vez que cambio algo en el CV, una GitHub Action lo compila para comprobar que no hay errores y guarda los PDF.
