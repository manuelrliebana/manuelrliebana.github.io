The website

Hand-written HTML and CSS, no frameworks, published with GitHub Pages. The only JavaScript is the wireless link chart, and the page reads just as well without it.

  • Spanish and English as static pages linked to each other.
  • Automatic light and dark mode based on your system settings.
  • Keyboard accessible with a visible focus, and it respects reduced motion settings.
  • Adapts from phones to large screens with a single stylesheet.

The brand

I designed my own logo: "liebana" in Bricolage Grotesque with a tilted diamond over the e. The diamond is the only coloured element, in amber, and here it also frames my photo and marks the points on the timeline.

The colours come from Jamilena, my home town: olive-grove green for the dark blocks and whitewash white for the background.

The CV in Typst

I write my CV in Typst, a code-based typesetting system. A single file builds the Spanish and English versions depending on the language I pass in, with the same fonts and colours as the website.

Every time I change the CV, a GitHub Action builds it to check for errors and saves the PDFs.
